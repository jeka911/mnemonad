Mnemonad is an infinite bytes[] that lives entirely on-chain on Monad — append-only and unbounded in length, exposed as an ERC-721 NFT so each "stream" is a token you own, can grant others write access to, and can optionally encrypt client-side. Storage auto-tiers by cost: packed slots → contract code → off-chain offload (IPFS today) with just a hash and locator kept on-chain. This explorer reads and writes real streams on Monad testnet/mainnet — not a mockup.

Monad is a high-performance layer-1 blockchain that is EVM compatible at the bytecode level, so Ethereum contracts and tooling run on it unchanged. It targets a 400ms block time with a 200M gas block limit and a 30M gas limit per transaction.

Two differences from Ethereum matter when reading anything on this site. Monad charges a transaction's gas limit rather than its gas used, so an overestimated limit costs real money. And the maximum contract size is 128 KB rather than Ethereum's 24 KB, which makes storing data as contract code practical.

Networks: Monad mainnet is chain id 143, explorer monadscan.com. Monad testnet is chain id 10143, explorer testnet.monadexplorer.com, with a faucet at faucet.monad.xyz. Switch between them in the header; the choice is remembered and reloads the app.
